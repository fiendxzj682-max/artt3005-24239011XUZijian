# Decaying Record

An archival specimen label card that gradually loses its recorded memory over time.

## Project Structure
- `decaying-record/record.html`: The interactive 3D flipping card with CSS decay animations.
- `decaying-record/record.json`: Data file containing catalog ID, title, date, place, and what was not captured.
- `decaying-record/assets/record.jpg`: Image of the record.
